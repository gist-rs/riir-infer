# Research 011: Kolmogorov-MDL Description Length Objectives for Transformers

**Source:** [arXiv:2509.22445](https://arxiv.org/abs/2509.22445) — "Bridging Kolmogorov Complexity and Deep Learning: Asymptotically Optimal Description Length Objectives for Transformers", Peter Shaw, James Cohan, Jacob Eisenstein, Kristina Toutanova (Google DeepMind / Google Research), **ICLR 2026** (v3 2026-03-02).
**Status:** RECORD — Gain verdict, two tracks. Modelless track: riir-infer Issue 040 (weight-histogram MDL audit POC). Training track: riir-train Plan 454 (staged, kill-gated MDL fine-tune POC). NOT Super-GOAT — the headline audit technique is published (EntroLLM arXiv:2505.02380; Deep Compression Han et al. 2016); the theory is validation-grade, not primitive-grade, for this repo.
**Date:** 2026-10-10
**Related:** katgpt-rs R558 (SLT/WBIC — the C_bayes-side selection currency, shipped default-on), katgpt-rs R125 + riir-train R016 (weight norm ≈ K(s) in fixed precision — the Lp/norm surrogate the B.9.2 law demotes), katgpt-rs R090 (epiplexity — time-bounded MDL, this paper's abstract parent), riir-train Plan 404 (λ̂ + WBIC LoRA-rank selection — gains the histogram-MDL column via Plan 454), riir-train Plan 454 (the training half of this distillation).

## TL;DR

The paper bridges algorithmic information theory and Transformers: a two-part MDL code whose hypothesis space is computationally universal and whose prior assigns at least one hypothesis per computable model function a codelength equal (up to a constant) to the function's Kolmogorov complexity is **universal** — its minimum equals `C_two-part(Y|X) = min_f K(f) − log₂ p(Y|X;f)` up to an additive constant, for ANY dataset. Transformer encoder families are asymptotically optimal in this sense (proven via an ALTA-compiler `zmap` construction: `Rs` prepended prompt-token embeddings carry the program as ±1 weights; layerwise-shared attention/MLP weights emulate a universal prefix Turing machine). Tractable instances exist: **adaptive variational codes with GMM prior and posterior**, where compression = soft quantization of weights onto mixture components. The empirical half is a controlled NEGATIVE: from random init, Adam/SGD fail to find the low-complexity solution (learned prior collapses to unimodal; parity KL 2.8×10⁶ vs 8.7×10² for the compiled init); the objective *selects* well but gradient descent does not *find*.

**For this repo, three modelless extractables survive the novelty gate as APPLIED utilities (not primitives):** the B.9.3 closed form (weight-histogram entropy `N·H(p)` = the description-length floor of any discretized weight group → Issue 040's audit), the B.9.2 multimodal-prior law (1 bit/bit for delta-mixture priors vs ≫1 for unimodal — a selector between quantization families), and the Table 2 bound decomposition (quantization + adaptive prefix + weight sharing ⇒ `|z| + log Rs`; ablations degrade to `O(Rs)`, `O(Rs)+O(Rt)`). The training-track half (can MDL-regularized training beat plain LoRA at equal quality and smaller shipped bytes?) files as riir-train Plan 454 — the paper's own negative result is real but narrow (random-init + *adaptive* prior), and warm-start + frozen-histogram-prior init bypasses the documented failure mode.

## The theory in one section

- **Universal two-part codes (Def 2, Prop 1).** A code `M = ⟨H_M, m_M, α_M⟩` (hypothesis space, mapping to model functions, prior) is universal iff for any other two-part code `M₂`: `L*_{M}(Y|X) +≤ L*_{M₂}(Y|X)` for all datasets. Universality needs exactly two properties: computational universality of the model class, and a prior that gives the shortest function-describing hypothesis a codelength `=+ K(f)`. Note (B.4.3): most hypotheses may be coded INEFFICIENTLY — universality only requires one efficient encoding per function. Redundant parameter spaces are fine.
- **Asymptotic optimality for Transformer encoders (Thm 1).** With `R = (R_t, R_s)` resource bounds, `zmap(T, R, z)` compiles any program `z` of a universal prefix Turing machine into Transformer weights (prompt rows = program tape as ±1 embeddings; shared layer weights = the interpreter). Weight count is invariant in `R_t` (layer sharing) — only prompt rows scale with `R_s`. A prior assigning `−log₂ α(h_z) = |z|` (or `< |z| + c_T`) completes the construction. Practical relaxation (Table 2): quantization + adaptive prefix length + weight sharing achieves `|z| + log Rs`; each ablation degrades the bound by a multiplicative `O(·)` factor, ultimately to the naive `O(R_s) + O(R_t)` uniform encoding.
- **Variational codes and the bound chain (Prop 3).** `K(Y|X) ≤+ C_bayes ≤+ L*_var ≤+ C_two-part`, where `C_bayes = −log₂ Σ_f 2^{−K(f)} p(Y|X;f)` (the universal Bayesian code, i.e. Solomonoff weighting). Quasi-universal variational codes reach the two-part bound. GMM prior + GMM posterior with per-feature-column shared priors achieves asymptotic optimality (Thm 2): delta-component posteriors at compiled weights; prompt rows past `|z|` carry posterior = prior (Rademacher) so they transmit **for free**; total KL = `|z| + c_T`.
- **B.9.3 closed form (the applied gold).** For a weight group quantized to `M` unique values with counts `c_i`: the optimal GMM prior is delta components at those values with mixing weights = empirical frequencies `p_i = c_i/N`, and the optimal code cost is `N·H(p)` — the Shannon entropy of the weight-value histogram. (This is why dynamic quantization (Han et al. 2016) and variational MDL are the same object under delta-component limits.)
- **B.9.2 multimodal law.** Encoding one bit through a unimodal Gaussian prior costs ≫1 bit of KL to reach reliable decoding; through a 2-delta mixture it costs exactly 1 bit. **Multimodality of the prior is load-bearing** — any complexity surrogate that is norm-like / unimodal-shaped (weight decay, Lp norms, fixed-constant proxies) sits in the loose class. This demotes fixed-constant `description_length` proxies (e.g. the `16 bits/rule` constants in katgpt-pruners `regime_transition.rs`) to measurable-entropy replacements.
- **The negative result (§6.1, §C.1–C.2).** Parity (42-layer tiny encoder, ALTA-compiled init as the known low-complexity solution): compiled init + variational objective = KL 8.7×10² bits, 100% OOD accuracy; random init + Adam = KL 2.8×10⁶, OOD 60.4%; SGD worse; the learned prior collapses to unimodal. On the MLP identity task the gap is largely a KL-coefficient artifact (3.4× at the tuned coefficient). The authors name the open problem: optimization procedures that discourage prior collapse, or alternative code families.

## Distillation for this repo (public substrate scope)

1. **`N·H(p)` description-length audit of shipped quant formats** → **Issue 040** (POC). For any discretized weight group — q2_0/PQ2 codebook indices, EXL3 trellis indices, k-quant symbols, ternary trits — the histogram entropy is the two-part MDL floor in bits/weight; the gap to nominal bpw is the format's entropy slack, computable in one O(N) metadata pass with zero dequantization. Report-only; not a codec. f16 tensors: computable but the optimality claim does not attach (histogram entropy of continuous values is codec-dependent) — report as advisory only.
2. **Format-selection lens (B.9.2 law).** A weight distribution whose histogram is low-entropy (mass concentrated on few values — exactly what ternary/PQ formats produce or exploit) is *designed* for delta-mixture codes; a near-Gaussian distribution pays ≫ under any fixed alphabet and wants residual-coding formats instead. As a routing heuristic between format families this is closed-form; promotion would be owner-gated and lossy-surface-gated (per-family conditional retention, never aggregate parity — the flat-aggregate trap the wider stack already paid for).
3. **Validation of the quant-family bet (Table 2).** The near-ideal `|z| + log Rs` bound is achieved by exactly the mechanism class this repo ships: discrete codebooks/alphabets (q2_0, EXL3 trellis, ternary) + adaptive selection + weight-shared or reused structures. The theory is asymptotic and the paper itself cautions (§4.2) that additive constants only wash out as datasets grow — quote it as a worst-case structural endorsement, never as a per-checkpoint optimality claim.
4. **Two-part selection currency beside WBIC (fusion with katgpt-rs R558's shipped `slt`).** `C_two-part` is an UPPER-bound selection currency requiring no posterior fitting: score a frozen candidate by `K̂(f) := Σ_g N_g·H(p_g)` over its discrete parameters + held-out fit `−log p`. WBIC estimates the `C_bayes` side; the two sandwich one target from opposite sides. Landed via riir-train Plan 454 Phase 2 (a zero-GPU column in Plan 404's checkpoint sweep), not as a separate primitive — the LLC↔MDL correlation axis is published (Timaeus 2025-10-13, "Compressibility Measures Complexity: MDL meets SLT", Pythia suite), so only the applied selection column is ours.
5. **Method inversion (the paper's real lesson for an inference substrate).** The bound-achieving objects are all COMPILED, never optimized: `zmap` compiles programs into weights and the compiled init is the only posture that holds the low-KL solution. For deterministic small artifacts (gate matrices, lookup policies, calibration tables), compile-then-freeze dominates train-then-pray. This is doctrine, not code.

## Fusion

- **× R558 (SLT/WBIC, shipped):** the paper supplies the missing coding-side twin of WBIC. WBIC = `nL + λ·log n` estimates the Bayesian-side cost; `N·H(p)` + held-out NLL estimates the two-part-side cost; Prop 3's chain `C_bayes ≤ L*_var ≤ C_two-part` makes them comparable on one axis. Plan 454 Phase 2 operationalizes the pairing in Plan 404's rank-selection sweep.
- **× R090 (epiplexity):** R090's `MDL_T = S_T + H_T` decomposition is the abstract time-bounded MDL; this paper instantiates the observer as a Transformer family with explicit `(R_t, R_s)` bounds and proves the bounds are ACHIEVABLE by real architectures (Thm 1). No new code; it upgrades R090's conceptual frame to a construction.
- **× R125 (weight norm ≈ K):** R125's sandwich bound prices fixed-precision weight NORMS as K-surrogates. B.9.2 explains why those surrogates are loose (unimodal-shaped priors pay ≫1 bit/bit) and what replaces them at equal cost: the measured histogram entropy. R125 keeps its THEORETICAL VALIDATION verdict; this note supplies the measurable currency its "constants are conceptual, not predictive" caveat asked for.
- **× The GDN/looped lane (weight sharing):** Table 2's weight-sharing row is the formal statement that shared-recurrence architectures carry no description cost in the time bound — a structural argument for the recurrent/GDN class that costs nothing to quote.

## Prior art (§4 search, 2026-10-10)

- **No follow-ups, critiques, or replications** of arXiv:2509.22445 surfaced (arXiv API + web; Semantic Scholar rate-limited). OpenReview hosts the ICLR 2026 camera-ready; no public rebuttal thread found.
- **The audit technique is published** — this is the Q1 kill for primitive-grade claims: EntroLLM (arXiv:2505.02380, May 2025) entropy-encodes quantized LLM weights (mixed quantization chosen to LOWER weight entropy, then Huffman: 7×/11.3× compression at 8/4 bits); community codebook-quantization repos Huffman-code frequency-sorted codebook indices (~10.5 vs 12–13 fixed bits/symbol); Deep Compression (Han et al. 2016) is the origin. What remains ours is only the applied audit position (report floor-vs-nominal per shipped format) → Issue 040, utility not primitive.
- **LLC↔MDL compressibility correlation is published** (Timaeus, 2025-10-13): SLT-based MDL extension over the Pythia suite with quantization/factorization. Does not do rank selection — Plan 404's applied lane stays open, but the correlation axis itself is not a novelty claim.
- **The prior-collapse training problem is unsolved**: no ≥1B-param GMM-prior variational MDL training run found; the paper's own empirics are the negative record. Plan 454's Phase 0 is staged against exactly this gap, with kill-gates.

## What this note deliberately does NOT claim

- No per-checkpoint optimality claims from the asymptotic theory (additive constants, finite resources — the paper's own §4.2 limitations).
- No novelty claim on histogram-entropy auditing (EntroLLM/Deep Compression lineage).
- No commitment that the variational MDL objective trains well — the source paper's headline empiric says it does not, from random init; Plan 454 exists to test the warm-start escape hatch, not to assume it.
- Private-tier serving-posture implications of this framework are recorded in the training-side plan (riir-train 454), not in this public note.

## Validation protocol (for Issue 040's audit)

- **G1 (correctness):** per-tensor `N·H(p)` must bit-match a reference entropy coder's output size on synthetic histograms and on sampled real GGUF groups (q2_0, EXL3, k-quants, ternary); f16/f32 rows reported as advisory. Side-info honesty: `N·H(p)` prices weight VALUES only — codebook + per-block-scale bits are reported as a separate side-info column, never pooled into the floor.
- **G2 (perf):** O(N) single metadata pass, no dequantization, no allocation in the scan loop; measured on the repo's named GGUF corpus with box-state provenance.
- **G3 (no regression):** read-only — decode paths byte-identical; no loader behavior change.
- **G4 (alloc):** streaming histogram counters, fixed-size alphabet tables per format.
