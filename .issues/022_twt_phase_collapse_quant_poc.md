## Phase 2 — Min-max DP partition

- [x] **T2.1** `minmax_partition(dist_oracle, n, eps) -> Vec<(usize, usize)>`: lexicographic DP — pass 1 minimizes block count under `S[j][i] ≤ ε`; pass 2 tie-breaks on worst-case boundary discrepancy. Total-order float compare (index-ordered argmin) — bit-identical cross-platform determinism. **TYPE-SPLIT feasibility (two tiers, not one):** (i) HARD-INFEASIBLE pair: different RoPE theta (laya: `rope_theta_full` ≠ `rope_theta_slide`, riir-infer-laya config.rs:141-150 — Q/K trained against different bases cannot average into a coherent operator), and GDN vs attention layers (Bonsai hybrid). (ii) FEASIBLE across MASK type only: sliding vs global with the SAME RoPE theta (gemma-2 carries ONE theta for both types — its GGUF metadata has no per-type rope keys, unlike laya's `rope_parameters.{kind}.rope_theta`; verified via riir-train `scripts/plan402_gguf_probe.py`) — the audition then PICKS the mask type (T3.1), and the above-window calibration length (T5.1) is what makes that choice testable. Without tier (ii), gemma-2's alternating pattern forces every same-type block to size 1 → m = L → a false "no phase structure" negative by construction. GENERALIZE-OR-NEIGHBOR vs the shipped `katgpt-core/src/ugc_schedule.rs:692 dp_partition(profile, k)` (contiguous K-block DP, sum-of-costs oracle at fixed k): extend it with the min-max-ε objective, or land the new DP beside it with a doc cross-link — never two partition DPs that don't know about each other. **LANDED 2026-09-27: `src/twt/partition.rs` — NEIGHBOR with a doc cross-link (different objective: min-MAX under ε, k free, vs fixed-k sum-of-costs); O(L²) worst-table (descending-i column-prefix recurrence) + feasibility monotonicity early-stop; blocks half-open `[start, end)`; `forced_min_blocks(types)` counts maximal same-type runs (the achievable floor the kill rule reads).**

## Phase 3 — Audition + zero-training surrogate

- [ ] **T3.1** Candidate pool per block: {each member layer passthrough} ∪ {weight-averaged operator f̄_j} ∪ {RDSC operator `θ_l + Σ(θ_{l+k} − θ_l)` — LaCo's difference-sum merge, so the pool contains the published zero-training class, not just our f̄} — merged weights, **norm/RMS/LayerScale params isolated** (menu: from block-final member / merged / from audition-best — pin one in artifact metadata). The surrogate's TYPE is explicit, never inherited implicitly: mask (full vs sliding), window size, and RoPE theta are taken from the audition-best member and recorded in the block-table metadata. GDN blocks: gate/decay params (A_log, dt biases) NEVER averaged (exp/sigmoid distortion) — copy from the audition-best member.
- [ ] **T3.2** Audition = argmin of local mapping error ‖f(h_{s−1}) − h_e‖² on the calibration batch, **evaluated in deployment arithmetic** (born-quantized audition: ternary path if deploying ternary — auditioning in f16 and deploying ternary optimizes the wrong objective). Selection BLAKE3-pinned (determinism gate); argmin-actually-the-min cross-check arm.
- [ ] **T3.3** Closed-form per-block corrections, fitted on the BRANCH: `h_e ≈ h_{s−1} + α·(f̄(h_{s−1}) − h_{s−1}) + β` — least-squares scalar or per-channel α (expect ≈ k: k merged residual layers produce ≈ h + (1/k)ΣΔᵢ, so the branch carries a 1/k shortfall the correction must restore), frozen into artifact metadata. NEVER whole-stream scaling (`α = E‖h_e‖/E‖f̄(h)‖`) — the residual stream's norm is dominated by h_{s−1}, so it corrects ≈ nothing or distorts the skip path. Gate: boundary-MSE decomposition raw vs +α vs +αβ on held-out calibration — record what fraction of distillation's boundary gain the branch fit recovers (pre-register the fraction floor; a miss is the honest No-GD loss boundary, not a silent pass, and must NOT bias the track split toward riir-train 423).
