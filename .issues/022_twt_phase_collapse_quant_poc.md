## Goal

Build the model→model collapse lane in this repo's declared domain (loaders/quant/architectures): profile a checkpoint's depthwise phase structure, partition it, audition a zero-training surrogate per block, emit a collapsed GGUF, and GOAT-gate it on decode throughput against pre-registered quality budgets. Target artifacts, in order: (1) the riir-infer-laya encoder lane (small, classification-shaped, Metal, existing G5-parity discipline), (2) Ternary-Bonsai-2-27B-PQ2 (the league model; decode is GPU-busy-bound — depth cuts move the league number directly).

## Phase 2 — Min-max DP partition

- [ ] **T2.1** `minmax_partition(dist_oracle, n, eps) -> Vec<(usize, usize)>`: lexicographic DP — pass 1 minimizes block count under `S[j][i] ≤ ε`; pass 2 tie-breaks on worst-case boundary discrepancy. Total-order float compare (index-ordered argmin) — bit-identical cross-platform determinism. **TYPE-SPLIT feasibility (two tiers, not one):** (i) HARD-INFEASIBLE pair: different RoPE theta (laya: `rope_theta_full` ≠ `rope_theta_slide`, riir-infer-laya config.rs:141-150 — Q/K trained against different bases cannot average into a coherent operator), and GDN vs attention layers (Bonsai hybrid). (ii) FEASIBLE across MASK type only: sliding vs global with the SAME RoPE theta (gemma-2 carries ONE theta for both types — its GGUF metadata has no per-type rope keys, unlike laya's `rope_parameters.{kind}.rope_theta`; verified via riir-train `scripts/plan402_gguf_probe.py`) — the audition then PICKS the mask type (T3.1), and the above-window calibration length (T5.1) is what makes that choice testable. Without tier (ii), gemma-2's alternating pattern forces every same-type block to size 1 → m = L → a false "no phase structure" negative by construction. GENERALIZE-OR-NEIGHBOR vs the shipped `katgpt-core/src/ugc_schedule.rs:692 dp_partition(profile, k)` (contiguous K-block DP, sum-of-costs oracle at fixed k): extend it with the min-max-ε objective, or land the new DP beside it with a doc cross-link — never two partition DPs that don't know about each other.
- [ ] **T2.2** G1: brute-force enumeration agreement for L ≤ 12 (all 2^{L-1} partitions: minimal m AND tie-break winner); monotonicity (m non-increasing in ε); every emitted block satisfies its constraint.
- [ ] **T2.3** G2: µs-scale at n=4096 on a synthetic monotone oracle.

## Phase 3 — Audition + zero-training surrogate

- [ ] **T3.1** Candidate pool per block: {each member layer passthrough} ∪ {weight-averaged operator f̄_j} ∪ {RDSC operator `θ_l + Σ(θ_{l+k} − θ_l)` — LaCo's difference-sum merge, so the pool contains the published zero-training class, not just our f̄} — merged weights, **norm/RMS/LayerScale params isolated** (menu: from block-final member / merged / from audition-best — pin one in artifact metadata). The surrogate's TYPE is explicit, never inherited implicitly: mask (full vs sliding), window size, and RoPE theta are taken from the audition-best member and recorded in the block-table metadata. GDN blocks: gate/decay params (A_log, dt biases) NEVER averaged (exp/sigmoid distortion) — copy from the audition-best member.
- [ ] **T3.2** Audition = argmin of local mapping error ‖f(h_{s−1}) − h_e‖² on the calibration batch, **evaluated in deployment arithmetic** (born-quantized audition: ternary path if deploying ternary — auditioning in f16 and deploying ternary optimizes the wrong objective). Selection BLAKE3-pinned (determinism gate); argmin-actually-the-min cross-check arm.
- [ ] **T3.3** Closed-form per-block corrections, fitted on the BRANCH: `h_e ≈ h_{s−1} + α·(f̄(h_{s−1}) − h_{s−1}) + β` — least-squares scalar or per-channel α (expect ≈ k: k merged residual layers produce ≈ h + (1/k)ΣΔᵢ, so the branch carries a 1/k shortfall the correction must restore), frozen into artifact metadata. NEVER whole-stream scaling (`α = E‖h_e‖/E‖f̄(h)‖`) — the residual stream's norm is dominated by h_{s−1}, so it corrects ≈ nothing or distorts the skip path. Gate: boundary-MSE decomposition raw vs +α vs +αβ on held-out calibration — record what fraction of distillation's boundary gain the branch fit recovers (pre-register the fraction floor; a miss is the honest No-GD loss boundary, not a silent pass, and must NOT bias the track split toward riir-train 423).

## Phase 4 — Ternarize arms + collapsed GGUF writer

- [ ] **T4.1** Three deterministic re-ternarization arms for f̄_j: (A) f16-dense surrogate (one GEMM per block replaces k ternary matvecs), (B) sign/majority re-ternarize (`sign(Σwᵢ)` where `|Σwᵢ| ≥ τ` else 0; integer arithmetic), (C) source-quantizer re-quant (effective averaged weights through the SAME absmean/group-128 formula, reusing the group-scale format). Gate adjudicates A/B/C — never pick by taste.
- [ ] **T4.2** Per-block mapping-error budget: ternarized f̄_j calibration error ≤ pre-registered multiple κ of the f16 f̄_j error (κ pinned in the gate before measuring).
- [ ] **T4.3** Collapsed-GGUF writer: model→model compiler emitting reduced layer count + `twt.block_table` + provenance (parent-weights BLAKE3, block table, α/β, arm choice) as standard GGUF metadata keys; verify with riir-train's `scripts/plan402_gguf_probe.py` (that script lives in riir-train — this repo's `scripts/` carries only the fence gate; the probe reads the keys cross-repo, no edit needed).

## Phase 5 — GOAT gate (the falsification gate)

- [ ] **T5.1** Lanes, in order: (1) **gemma-2-2b f16** — the CHEAPEST control, and its zero-training arm is riir-train 423 Phase 1's baseline (one artifact, two consumers); pin at least one calibration length ABOVE the 4096 sliding window — below it, sliding and global layers are indistinguishable and the gate goes green while silently changing long-context behaviour (the green-zero shape); (2) laya encoder (classification-shaped — the favorable class); (3) Bonsai PQ2 27B (league-relevant; decode is GPU-busy-bound so depth cuts move the league number). G3 budgets pre-registered BEFORE measurement per lane: collapsed-vs-parent **absolute** top-1 agreement ≥ 0.9 on frozen fixture prompts (the parent trivially agrees with itself at 1.0 — the bar is absolute, not a ratio) + suite-level drop ≤ Δ_max; generation/reasoning lanes measured and reported honestly with the layer-pruning-harms-reasoning caveat (arXiv Aug 2026) — expected penalty axis, never hidden.
- [ ] **T5.2** The 2×2 CONTROL on every lane: parent precision (f16 | quantized) × (collapsed | not) — the novelty claim rests on quantized checkpoints, so the gate must SEPARATE collapse error from quantization interaction; ΔS localizes damage, it does not adjudicate this cell.
- [ ] **T5.3** G2 perf: collapsed decode tg/pp vs parent at matched quality floor (M3 Metal first; 4090 optional — via issue, the box may be busy); KV-memory-per-token m/L assertion; profiler samples/sec floor at L=64/D=6144.
- [ ] **T5.4** Arms at EQUAL FLOP reduction: full parent vs zero-training collapsed (this lane) vs **hydra-skip** vs **LaCo-RDSC merge** vs **ShortGPT removal** — the published zero-training LLM class must be IN the gate or the claim cannot be said to beat it; a loss to any arm hardens that arm's pin (honest negative, recorded).
- [ ] **T5.5** ε-sweep Pareto report: (m, params, FLOPs, eval) per pre-registered ε point → `.benchmarks/` with box-state provenance on every latency number; monotonicity of m in ε asserted (a violation is a Phase 2 bug).
