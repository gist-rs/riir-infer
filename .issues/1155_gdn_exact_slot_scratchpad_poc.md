# Issue 1155 — POC: exact slot-addressable GDN state (the Qwenputer identity on our kernels)
**Status:** Resolved 2026-10-29 — G1a/G1b/decay/journal-hypothesis/G4 all LANDED (`tests/issue1155_exact_slot_gdn.rs` 7 tests + `tests/issue1155_exact_slot_g4_alloc.rs`); the hypothesis CONFIRMED: keep/halve in-domain journal unwind restores bit-exactly. Premise corrected in verdict round 1: exactness is a value-domain contract, NOT delta-rule algebra (G1 split into G1a/G1b accordingly). Stretch wgpu cell unclaimed (owner-gated).

## Premise

Qwenputer (divagr18/qwenputer @ `ca13310e`, MIT) runs a RISC-V CPU inside Qwen3.5-4B by driving its Gated DeltaNet layers as exact, addressable RAM: one-hot keys address one cell, gate = 1, write-β = 1, and — the load-bearing part — the payload lives on an **exact grid** (bounded integers) enforced by compile-time validators. ⚠ **The algebra alone does NOT give bit-exactness on our kernel**: `gated_deltanet_step_inplace` (`src/deltanet/forward.rs` L250-258) writes the addressed cell as `S[row,j] + b·(v[row] − S[row,j])` (the delta form). With b = 1 that is `a + (v − a)`, which is **not** `v` for arbitrary f32 — cancellation: a = 1e8, v = 1.0 → `0.0`. It IS `v` bit-exactly when payloads are bounded integers with |a|, |v|, |v−a| ≤ 2^24 (subtraction and re-addition exactly representable). The readout dot sums over ALL key columns, so the domain contract must also require **finite-only state** (`inf·0 = NaN` inside `simd_dot_f32` otherwise).

Our deltanet lane owns the same substrate (Bonsai-27B: 48 GDN layers; qwen3.8 arch twin family) and has never *proved* the identity — either direction. The `GdnStateJournal` (delta_roll, Issue 049) pins its f32 unwind with a drift floor because general state restore is "algebraically exact, NOT bit-exact" (its law 2). This POC establishes: (G1a) in-domain slots are bit-exact memory cells, (G1b) arbitrary-f32 payloads break it (negative control — pre-empting the Issue-825 false-negative "the identity does not transfer"), and (hypothesis) in-domain pinned slots restore bit-exactly through the journal under keep/halve.

**Orientation:** our state is `S[val_row, key_col]` (`row * key_dim + col`); a one-hot key addresses a key **column** j across all value rows — Qwenputer's "row" wording is transposed for our layout; assertions index columns.

Full construction-law set (L1–L8): `../.research/018_Qwenputer_GDN_Exact_RAM_Compiled_CPU.md`. Determinism law: any f32 fold in the proof follows katgpt-rs Issue 940 (sequential order, fixed tie rule).

## Tasks

- [x] **G1a (CPU, in-domain battery):** over `gated_deltanet_step_inplace` — gate=1, β=1, one-hot key column, payloads on the exact grid (bounded integers: |a|, |v| and |v−a| all ≤ 2^24 — every intermediate exactly representable), finite-only state ⇒ every addressed cell round-trips **bit-exactly** and every non-addressed cell is **bit-unchanged**; sweep head counts and K/V widths. LANDED: shapes (1,16,8)/(2,64,16)/(8,128,128) incl. the real Bonsai geometry; grid-edge payloads ±2^23/±2^24/0; per-head one-hot keys (full-width [h·kd]); readout leg bit-exact at K ∈ {16,64} (scale a power of two).
- [x] **G1b (CPU, negative control — must FAIL):** the same battery with arbitrary-f32 payloads ⇒ assert mismatches occur (include the cancellation pair a=1e8, v=1.0 → 0.0 as a named case). G1b passing (zero mismatches) is a harness bug, not a success. LANDED: cancellation pair collapses to exactly 0.0; the overflow row poisons via inf·0=NaN across kd−1 columns; random battery asserts mismatches > 0.
- [x] **Decay-selector semantics:** keep (g=1) and halve (g=0.5) are exact power-of-two state scalings; clear (g=0) zeroes the state exactly (destruction, forward-side). Halving-counter rows reach 2^-n exactly within the f32 exponent range (normals to 2^-126; subnormals to 2^-149 with reduced guarantee — an exponent bound, not a mantissa one). LANDED with two MEASURED refinements: (1) 2^-149·0.5 ties-to-even into 0.0 (the ladder runs to 2^-149 exact, then 0.0); odd-mantissa subnormals round to even (3·2^-149 → 2^-148, not 1.5·2^-149). (2) Under clear the state lands on +0 UNIFORMLY — x·0's sign(±0) is rewritten by the delta=+0 addend in the same step, so sign(x) is not observable post-step.
- [x] **G4:** zero-alloc hot path for the proof harness (counting allocator, own binary — the delta_roll G4 pattern). LANDED: `tests/issue1155_exact_slot_g4_alloc.rs` ([[test]] row, required-features gdn_delta_roll), rig-built buffers, 256 writes + records + unwind = 0 allocs (release).
- [x] **G3:** byte-identical default posture (the POC ships as a gated demo/test; no serving-path change). HOLDS by construction: zero production source touched — two test files + one Cargo.toml [[test]] block only.
- [x] **Journal interplay (HYPOTHESIS, pre-registered):** an in-domain pinned-slot region journaled + unwound via `GdnStateJournal` under **keep/halve** restores bit-exactly (exact scaling + same-grid subtraction). **Clear is out of scope** — journal law 1 refuses g=0 windows ("irreversible by construction"). A failure here is a RESULT (record drift + refine the hypothesis), never silently rewritten into the premise. **CONFIRMED — the headline result:** keep/halve unwind to EVERY target (snapshots[0..=T]) is BIT-EXACT over schedules [1.0,0.5,1.0] (default eps 0.25) and 8×0.5 (eps 2^-8, the gate passing AT equality); journal law 2's "algebraically exact, NOT bit-exact" is REFUTED IN-DOMAIN — the scale-then-add vs subtract-then-scale reassociation rounds nothing when every intermediate is on the exact grid and every scaling a power of two. Law 1's fail-closed g=0 refusal re-verified (Err + state bits untouched). NOTE for the law text: out-of-domain payloads still drift exactly as law 2 says — the law is not wrong, it was stating the general case; the PoC adds the in-domain exception.
