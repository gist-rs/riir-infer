# Issue 027 — offline LUT grid optimization lane: encoder-only asymmetric Q2_0 first, then Q2_0A

**Status:** CLOSED — MEASURED NEGATIVE at the model-level gate (Plan 615 T6, 2026-10-01). The weight-space wins were real (T0 +4.9 dB/family, Q2_0A +0.5–1.2 dB/family over T0, both dense artifacts) but the 2-bit class is function-destroying on our dense artifacts: MiniCPM5-1B ppl 6.8e5–7.0e6 vs base 49.8, EVERY family (chat + docs), EVERY reachable granularity (per-128/64/32) — the lane's own gate ("a per-family loss at matched bpw = recorded negative, lane closes") fires on the whole class, not one arm. The Bonsai ternary lane is untouched (byte-identity control held). The paper's 27B dense regime is UNMEASURED here (infeasible with the fakequant harness on both boxes) — recorded as the honest limit.

Master: `.research/004_DQ_Disaggregated_Quantization.md` (arXiv:2609.26333 §2.3 + Appendix A.3). Factual basis in our code: `q2_0` already **decodes** a fourth code state — code 3 = **+2d** (`q2_0.rs` line 99 "Preserves the fourth state"); only the reference **encoder** never emits it (it sets `d = amax`, so `w/d ∈ [-1,+1]` and the 30.72M-weight scan found zero code-3 occurrences). The block scale is **single-level f16 per-128** — there is no tensor-level f32 scale in our q2_0 (the paper's two-level scaling is their structure, not ours). Consequences shape the whole lane below (verdict-review corrections, round 1).

## Tasks

- [x] **T0 — encoder-only asymmetric Q2_0 (the cheapest arm; no new format).** LANDED Plan 615 T3: `quantize_row_q2_0_asymmetric` (`src/quant/q2_0.rs`) — signed `d = sign(argmax|w|)·f16(amax/2)`, first-index argmax (the A2 convention, shared with the activation lane), anchor always code 3 (tested). Weight-space: +4.9 dB/family over the symmetric reference on both dense artifacts. Pick a SIGNED `d = ±amax/2`, sign chosen so the block's largest-magnitude element lands on **+2d** (f16 d supports negative; the existing bytes and the existing decode path carry it unchanged). The effective grid becomes `{-d, 0, +d, +2d}` with the scale sign steering which side gets the double step — the paper's asymmetric-grid insight, encoder-only. GGUF-compatible (the format semantics already define code 3); consumers that route through the ternary bridge are excluded by T4's finding until that kernel exists.
