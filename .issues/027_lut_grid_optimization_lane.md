# Issue 027 — offline LUT grid optimization lane: encoder-only asymmetric Q2_0 first, then Q2_0A

**Status:** OPEN — format-lane experiment; GOAT-gated; a per-family loss at matched bpw = recorded negative, lane closes. GAIN SITE IS THE DENSE-GGUF ARM ONLY — the Bonsai ternary arm is a byte-identity control and is NOT a consumer of this lane.

Master: `.research/004_DQ_Disaggregated_Quantization.md` (arXiv:2609.26333 §2.3 + Appendix A.3). Factual basis in our code: `q2_0` already **decodes** a fourth code state — code 3 = **+2d** (`q2_0.rs` line 99 "Preserves the fourth state"); only the reference **encoder** never emits it (it sets `d = amax`, so `w/d ∈ [-1,+1]` and the 30.72M-weight scan found zero code-3 occurrences). The block scale is **single-level f16 per-128** — there is no tensor-level f32 scale in our q2_0 (the paper's two-level scaling is their structure, not ours). Consequences shape the whole lane below (verdict-review corrections, round 1).

## Tasks

- [ ] **T0 — encoder-only asymmetric Q2_0 (the cheapest arm; no new format).** Pick a SIGNED `d = ±amax/2`, sign chosen so the block's largest-magnitude element lands on **+2d** (f16 d supports negative; the existing bytes and the existing decode path carry it unchanged). The effective grid becomes `{-d, 0, +d, +2d}` with the scale sign steering which side gets the double step — the paper's asymmetric-grid insight, encoder-only. GGUF-compatible (the format semantics already define code 3); consumers that route through the ternary bridge are excluded by T4's finding until that kernel exists.
- [ ] **T1 — offline Lloyd-Max grid solver.** Minimize `E[(w − Q(w))²]` over the EMPIRICAL weight histograms of our DENSE GGUF artifacts, under our actual scale structure — **f16 per-128, single-level**. Adding a tensor-level f32 scale is an EXPLICIT solver axis (evaluate with and without; it costs 4 B/tensor of metadata), never an assumption. Constrain the grid to contain 0 and the scale anchor. Determinism gate: the solver is a pure function of (weight stats, scale structure, level count) → BLAKE3-committed grids, byte-identical across M3 and 4090.
- [ ] **T2 — Q2_0A format (non-uniform levels).** Lloyd-Max levels replace the uniform `{-1,0,+1,+2}·d` ladder; sign-absorbing scale as in T0. Same 34B block layout (2-bit codes + f16 per-128 scale). **The bar is T0, not the ternary encoder:** Q2_0A must beat T0 at matched bpw, or its gain is T0's and the new format name is unjustified.
- [ ] **T3 — G1 at matched bpw.** Dense-GGUF arm is the ONLY place a gain can appear. The **Bonsai arm cannot gain by construction** — its weights are trained ternary with values exactly `{-1,0,+1}·d` and zero code-3 occurrences, no pre-quantization masters exist, so re-encoding onto any other grid can only reproduce or lose. Keep Bonsai solely as a **byte-identity control** (encoder round-trip must reproduce the original bytes). Dense arm: per-family conditional retention (the lossy-surface law; never aggregate perplexity alone) — T0 (and T2 only if it beats T0) must win or tie per family or the lane closes.
- [ ] **T4 — kernel-path cost, stated up front.** T0/Q2_0A artifacts **cannot use the ternary sign-magnitude fast path**: the `Q2_0 → TernaryGroupWeights` bridge rejects code 3 loudly (`Q2oRepackError::UnsupportedFourthState`, `q2_0.rs:185-214`). So T4's G2 comparison is the LUT-decode kernel (in-corpus substrate: `lut16-pshufb-byte-expansion-at-stage`, one shuffle expands 16 codes) **against that ternary fast path**, at the league rows. GOAT promotion here means **shipping and maintaining a second 2-bit decode kernel**, not just an encoder change — the plan must price that maintenance, not hide it.
- [ ] **T5 — scale-granularity sweep.** per-128 (today) vs per-64/per-32 scale granularity at matched total bpw, plus the T1 tensor-level-f32 axis: does finer granularity buy more accuracy than the bpw it costs? Expected honest prior: negative at q2_0 (bytes are the point), possibly positive at q4k/q6k. Pin the winning granularity per bpw tier.

GOAT gate: promote any new encode default only if T3 wins per-family at matched bpw AND T4 holds with the kernel cost priced; demote otherwise. The Bonsai lane (our flagship) is untouched by construction.
